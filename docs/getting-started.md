# Getting Started

## Prerequisites

- Git
- Docker
- Kubernetes tooling (optional for local validation)
- Make

## Quick start

1. Clone the repository.
2. Review the repo structure.
3. Start from the `apps/demo-api` service.
4. Use the Makefile for common project commands.
